# 第 1300 步 EMA 的 9×9 人机对弈记录

2026 年 11 月 25 日，我在续训前和第 1300 步的 EMA 模型下了两盘围棋，执黑、执白各一盘。两盘下完，我都觉得自己一点赢的希望也没有。

## 对弈设置

棋盘为 9×9，贴 7 目，采用位置超级劫（`positional`）。MiniZero 使用 `step-001300.pt` 中的 EMA 权重，每手做 400 次 MCTS 模拟，选择访问次数最多的着法。对弈时关闭探索噪声和自动认输。 [对弈脚本](../../scripts/play.py)

## 启动命令

在仓库根目录执行，默认执黑。追加 `--color white` 可执白。

```powershell
docker compose run --rm --no-deps --entrypoint python dev -m scripts.play --checkpoint /workspace/runs/8dca442d-fb77-4fc6-8dfa-2a872fa7bdef/checkpoints/step-001300.pt
```
