第 74 轮的 40 盘全部零手认输。该轮第一条棋谱的 `ingest_seq` 为 2921，原文如下。

```text
SelfPlay true 0 0 -1 (;GM[go_9x9]RE[-1]OBS[]SZ[9]KM[7.000000]EV[model.pt]DLEN[0--1]) #
```

这里的 `0 0 -1` 分别表示 0 个训练位置、0 手和白胜。同期日志中的 `games=40` 是本轮已入库盘数，`new_games=4/40` 是上次模型更新后累计产出样本的盘数。经验池已有 `9033/2000` 个样本，新增有效棋局的门槛一直未达到。 [训练门槛实现](../../src/control/training_controller/training_controller.py#L243)

## 开局估值与认输

前四轮白胜 145 盘、黑胜 15 盘。145 盘白胜中，141 盘由双方停着后计分。固定这些棋谱的终局盘面，用零贴目重算这 141 盘，其中 42 盘变和、48 盘变黑胜、51 盘仍是白胜。这反映了贴目对这批既定走法的影响。

每盘的终局胜负用于该盘的每个训练位置。白胜棋谱给黑方回合标 `-1`，白方回合标 `+1`。前四轮的 160 个相同黑先空盘因此收到 145 个 `-1` 和 15 个 `+1`，只拟合这些空盘时，平方误差最小的估值是 `-0.8125`。第 12 步的训练模型实测为 `-0.9994`，用于自对弈的 EMA 模型为 `-0.9553`。回测最终黑胜的棋谱时，EMA 也把其中 1,008 个位置的黑方估值压到了 `-0.9` 以下，共有 1,371 个这类位置。 [价值标签](../../src/data/minizero_replay/minizero_replay.py#L120) · [价值损失](../../src/core/learner/gradient_accumulation/gradient_accumulation.py#L47)

用第 12 步 EMA 检查点重新导出模型，分别在四线程 `quiet = false`、四线程 `quiet = true`、单线程 `quiet = true` 下采集，三组的前 12 盘均为零手认输。异常日志中的首手根节点均值 `-0.9508` 和候选着法均值 `-0.9577` 都低于认输阈值 `-0.9`。日志中的 `move number: 0` 是搜索时已落子的手数，`action` 是搜索选出的候选着法。若随后认输，棋盘仍为空。

棋盘和搜索日志走标准错误，采集入口从标准输出读取完整棋谱。保留原四线程和搜索预算并禁用认输后，对照中的棋局走到了第 3 手。 [棋谱采集实现](../../src/data/minizero_selfplay/minizero_selfplay.py#L11)

## 下次实验

早期模型的估值偏差一旦触发首手认输，就会阻断纠正估值所需的新样本。观察自对弈进展时，应同时看 `games_with_samples`、`sample_count` 和训练 `step`。单看入库盘数和白胜率容易把快速认输当成有效采集。
