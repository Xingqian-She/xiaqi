# Move

`Move` 表示 MiniZero 围棋棋谱中的一手棋，保存执子方、动作编号以及该手附带的搜索数据。[实现代码](move.py)

| 字段 | 含义 |
| --- | --- |
| `player` | 执子方，黑方为 `1`，白方为 `2`。 |
| `action_id` | 动作编号。9×9 棋盘的落子点编号为 `0` 到 `80`，`81` 表示停一手（pass）。 |
| `policy_weights` | 棋谱 `P` 字段中的 `(动作编号, 权重)` 对，保留原始权重。缺省时为空元组。 |
| `search_value`、`reward` | 分别对应棋谱中的搜索估值 `V` 和该手奖励 `R`，缺省时为 `None`。 |
